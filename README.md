# Миний Хөтөч

Хувийн хуанли, профайл, CV, сертификат, санхүүгийн тооцоо нэг дор. Claude болон интернэтгүйгээр ажиллана. Бүх мэдээлэл зөвхөн таны утас эсвэл компьютерийн хөтөч дотор хадгалагдана.

## Энэ хавтсанд юу байгаа вэ

| Файл | Үүрэг |
|---|---|
| `index.html` | Апп өөрөө (бүх код, фонт, PDF уншигч дотроо) |
| `manifest.webmanifest` | Утасны нүүр дэлгэцэнд апп болгон суулгах тохиргоо |
| `sw.js` | Интернэтгүй үед апп-ыг нээгдэг байлгана |
| `icon-*.png` | Апп-ын дүрс |

## GitHub Pages дээр байршуулах (нэг удаа, 10–15 минут)

Компьютерээс хийхэд хамгийн хялбар.

1. **Бүртгэл үүсгэх.** https://github.com/signup хаягаар орж имэйл, нууц үг, хэрэглэгчийн нэрээ (username) оруулна. Имэйлээ баталгаажуулна. Хэрэглэгчийн нэр тань апп-ын хаягт орно.
2. **Шинэ repository үүсгэх.** Баруун дээд буланд байрлах **+** → **New repository** дарна.
   - **Repository name:** `khotoch`
   - **Public** сонгоно. GitHub-ийн үнэгүй багцад Pages зөвхөн Public repository дээр ажилладаг. Код л харагдана, таны мэдээлэл энд хадгалагдахгүй.
   - **Add README**-г асаана.
   - **Create repository** дарна.
3. **Файлуудаа оруулах.** Repository хуудсанд **Add file** → **Upload files** дарна. Энэ ZIP-ийг задлаад доторх бүх файлыг (`index.html`, `manifest.webmanifest`, `sw.js`, 4 ширхэг `icon-*.png`) чирж оруулна. Хавтсыг биш, доторх файлуудыг оруулна. Доод хэсгийн **Commit changes** дарна.
4. **Pages асаах.** Repository-ийн **Settings** → зүүн цэсний "Code, planning, and automation" хэсгийн **Pages** дарна.
   - "Build and deployment" хэсэгт **Source**: **Deploy from a branch**
   - **Branch**: `main`, хавтас: **/(root)**
   - **Save** дарна.
5. **1–10 минут хүлээх.** Pages хуудасны дээд хэсэгт "Your site is live at …" гарч ирнэ. Апп-ын хаяг: `https://ТАНЫ-USERNAME.github.io/khotoch/`

## Утсандаа суулгах

**iPhone (Safari):**
1. Апп-ын хаягийг **Safari**-гаар нээнэ.
2. Доод талын **Хуваалцах** товч (дөрвөлжин дотор дээш сум) → **Add to Home Screen** → **Add**.
3. Нүүр дэлгэц дэх "Хөтөч" дүрсээр нээнэ.

**Android (Chrome):**
1. Апп-ын хаягийг **Chrome**-оор нээнэ.
2. Баруун дээд **⋮** → **Add to Home screen** эсвэл **Install app** → **Install**.

**Компьютер:** Chrome эсвэл Edge-ээр хаягаа нээж, хаягийн мөрний баруун талд гарах суулгах товчийг дарна. Эсвэл зүгээр л bookmark хийнэ.

## Анх нээхэд

- **Жишээ мэдээллээр эхлэх** дарвал апп жишээ мэдээллээр дүүрнэ. Танилцаад дээд хэсгийн **Жишээг арилгах** товчоор арилгана.
- **Нөөц файл оруулах** нь өмнө нь татсан `Minii_Khotoch_noots_….json` файлаас мэдээллээ сэргээнэ.
- **Хоосноос эхлэх** дарвал шууд өөрийн мэдээллээ оруулж эхэлнэ.

## Мэдээллээ хамгаалах

- Мэдээлэл тань зөвхөн тухайн төхөөрөмжийн хөтөч дотор хадгалагдана. GitHub руу, интернэт рүү илгээгдэхгүй.
- Утас, хөтөч солих эсвэл хөтчийн "site data"-г цэвэрлэхэд мэдээлэл устна. Иймд **сар бүр** "Би" табын доод хэсгээс **Нөөц татах (файлтай)** дарж нөөцөө хадгална уу.
- Шинэ утас руу шилжихдээ шинэ утсан дээрээ апп-аа нээж, **Нөөцөөс сэргээх**-ээр нөөц файлаа оруулна.
- Мэдээлэл шифрлэгдээгүй. Утсаа заавал нууц код эсвэл хурууны хээгээр түгжээрэй.
- Нөөц файл таны бүх мэдээллийг агуулдаг тул хэнд ч бүү илгээгээрэй.

## Шинэчлэх

Шинэ `index.html` авсан бол repository-д **Add file** → **Upload files**-аар хуучныг нь дарж оруулаад **Commit changes** дарна. Хэдэн минутын дараа утсан дээрх апп-аа хоёр удаа хааж нээхэд шинэчлэгдэнэ. Таны мэдээлэлд нөлөөлөхгүй.

## Анхаарах

- AI зөвлөх, CV-г AI-аар задлах, AI хэмнэлтийн санал энэ хувилбарт байхгүй. Эдгээр нь зөвхөн Claude дотор ажилладаг.
- Апп-ын хаягийг мэдсэн хэн ч апп-ыг нээж болно. Гэхдээ хүн бүр өөрийн төхөөрөмж дээрх зөвхөн өөрийн мэдээллийг л харна.
